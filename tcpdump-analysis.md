# tcpdump Analysis

## Features

- Command-line packet capture
- Lightweight and efficient
- Powerful packet filtering
- Commonly available on Linux and Unix systems

## Typical Usage

Security analysts use tcpdump for remote packet capture, server troubleshooting, network monitoring, and incident response investigations where graphical interfaces are unavailable.

## Advantages

- Minimal resource usage
- Fast packet capture
- Excellent for remote environments
- Scriptable and automatable

## Limitations

- Requires command-line knowledge
- Less visual than Wireshark
- More difficult for beginners
